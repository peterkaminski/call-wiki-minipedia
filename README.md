# Call Wiki - Minipedia Prompt Library

_AI generated in dialogue with humans. Not fully reviewed._

A **call wiki** (also called a **minipedia**) is a method invented by Peter Kaminski for transforming the artifacts of a conversation — transcripts, chat logs, shared links, notes — into a richly interlinked wiki knowledge base using AI assistance.

Unlike a traditional meeting summary or AI-generated recap, a call wiki produces dozens to hundreds of interconnected wiki pages with `[[bidirectional links]]`, hub pages for navigation, concept indexes, participant profiles, and honest depth classification — brief mentions stay brief, deep discussions get full treatment.

## Origin

The call wiki concept emerged from the intersection of several of Pete's projects and interests:

- **Massive Wiki** — a wiki ecosystem built on markdown files and git, designed for collaborative knowledge work
- **MarkPub** — a static site generator that publishes Massive Wiki content to the web
- **Open Global Mind (OGM)** — a community exploring collective intelligence, where weekly calls provided the first test material
- **AI capabilities** — particularly Claude and Claude Code, which made it practical to process hours of transcript into structured, interlinked wiki content

The first call wikis were created for OGM calls in late 2025. The concept has since been applied to two-person conversations, team meetings, advisory calls, and even non-call structured content.

## Current State

Pete and others continue to evolve the call wiki / minipedia concept in the **Agentic AI with Pete** course and elsewhere. If you've built a call wiki, let Pete know so it can be added to the [[Call Wiki Catalog]]!
